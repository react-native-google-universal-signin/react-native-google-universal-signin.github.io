Installation

This guide will help you install and configure react-native-google-universal-signin in your React Native or Expo app.

⭐ Key Features​

Universal Sign-In is a powerful and flexible authentication solution that works across platforms, backed by official SDKs and optimized for speed and simplicity.

🌐 Cross-Platform Compatibility​

A unified API designed to work seamlessly across:

  • Android – Built with the Credential Manager library.
  • Web – Uses Sign In with Google for Web.
  • iOS & macOS – Powered by the Google Sign-In SDK.

  • Licensed for professional and commercial use — see Pricing & License.
  • Actively maintained and supported.

✅ Trusted by the Community​

  • Used in production apps across mobile and web.

⚡ Faster Sign-Ups​

According to Google, Credential Manager reduces sign-up/sign-in times on Android by up to 50%.

🛡️ Advanced Security Features​

  • OAuth2-based authorization
  • Secure token handling
  • Modern account linking capabilities
  • First-party SDKs for all platforms

🔧 Easier Setup​

  • Automatic detection of client IDs and configuration parameters.
  • Supports .well-known file discovery on web.
  • Optimized install and configuration guides per platform.

📱 Example App Included​

A complete example app is provided to showcase all features — native (Android/iOS/macOS) and web in one unified repo.

Requirements​

  • React Native 0.71 or higher
  • iOS 13+ and Xcode 14+ for Apple platforms
  • Android 5.0 (API level 21) or higher
  • Node.js 18+

Obtaining RN Google Universal Sign-In

To use the react-native-google-universal-signin module, you must first purchase a license. This license grants you access to:

  • A private npm package hosted on GitHub Packages.
  • A private GitHub repository containing usage examples.

Accessing the Private npm Package​

The private package is hosted on the GitHub npm registry, not the public npm registry. Therefore, some configuration is required.

1. Obtain a Personal Access Token (PAT)​

Create a GitHub Personal Access Token with the following permission:

  • read:packages

Once generated, store it securely. It is recommended to save it in an environment variable, e.g.:

export NPM_TOKEN_GOOGLE_SIGN_IN=your_token_here

2. Configure Your Package Manager​

Create a .npmrc file in the root of your project with the following content:

//npm.pkg.github.com/:_authToken=${NPM_TOKEN_GOOGLE_SIGN_IN}
@react-native-google-signin:registry=https://npm.pkg.github.com/

This configuration tells your package manager to:

  • Authenticate using your GitHub token.
  • Download @react-native-google-signin packages from the GitHub registry.

Package Manager Support​

Yarn v3+​

If you're using Yarn v3+, ensure your .yarnrc.yml also includes GitHub registry support. Refer to the Yarn documentation for advanced configuration.

npm / Yarn v1​

The .npmrc file shown above is fully compatible with npm and yarn v1.

Other Package Managers​

If you use another package manager such as Bun, pnpm, or others, refer to their respective documentation for configuring scoped package access from a custom registry like GitHub Packages.

Once this is set up, you’ll be able to install the package like any other:

yarn add @react-native-google-universal-signin
# or
npm install @react-native-google-universal-signin

Next steps depend on the type of project you are using:

  • If you are using Expo (bare or managed workflows), continue to Expo Setup.
  • If you are using a standard React Native project, follow React Native Setup.

⚠️ Make sure to also set up platform-specific configuration in android, ios, and web as detailed in their respective guides.
